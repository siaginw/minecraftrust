# Milestone M1.2: Input Validation & Buffer Capacities

## 1. Staging Buffer Schema (INPUT-A V1)
Explicit ABI Version: `M1_CHUNK_STAGING_V1 = 1`

### Binary Header (6 Bytes)
| Offset | Field | Type | Description |
| :--- | :--- | :--- | :--- |
| `0x00..0x01` | `schema_version` | `u16` (BE) | Must equal `1`. Mismatches return error `-7` (`UnsupportedAbiVersion`). |
| `0x02..0x03` | `primary_bit_mask` | `u16` (BE) | Bitmask of sections present in chunk (bits 0..15). |
| `0x04` | `flags` | `u8` | Bit 0: `full_chunk` (includes biomes); Bit 1: `skylight_present`. |
| `0x05` | `section_count` | `u8` | Number of sections staged. Must equal `count_ones(primary_bit_mask)`. |

### Section Descriptors (Per Present Section)
| Field | Type | Description |
| :--- | :--- | :--- |
| `section_index` | `u8` | Section Y-index (0..15). Must correspond to set bit in mask with no duplicates. |
| `bits_per_block` | `u8` | Bit-width (4..8 for indirect palette, 9..16 for global registry palette). |
| `palette_count` | `u16` (BE) | Number of palette entries. For `bits < 9`, must be $\le 256$. For `bits >= 9`, must be 0. |
| `palette_entries` | `u32[count]` | VarInt-ready block state IDs (up to 65535 in Forge). |
| `storage_words_count`| `u16` (BE) | Number of 64-bit storage words ($\le 1024$). |
| `storage_words` | `u64[count]` | Pre-packed BitArray words in Big-Endian order. |
| `block_light` | `u8[2048]` | Block light nibble array. |
| `sky_light` | `u8[2048]` | Sky light nibble array (present only if `flags & 0x02 != 0`). |

### Optional Tail
| Field | Type | Description |
| :--- | :--- | :--- |
| `biomes` | `u8[256]` | Biome array (present only if `flags & 0x01 != 0`). |

## 2. Capacity Calculations & Upper Bounds

### Staging Buffer Maximum Capacity Proof
For a full 16-section chunk with 16-bit global palette, all lighting, and biomes:
- Header: $6\text{ bytes}$
- 16 Sections:
  - Header: $1 + 1 + 2 = 4\text{ bytes}$
  - Palette: $0\text{ bytes}$ (global palette)
  - Words Header: $2\text{ bytes}$
  - Words Payload: $4096 \times 16 / 64 = 1024\text{ words} = 8,192\text{ bytes}$
  - Block Light: $2,048\text{ bytes}$
  - Sky Light: $2,048\text{ bytes}$
  - Per-section Total: $4 + 2 + 8,192 + 2,048 + 2,048 = 12,294\text{ bytes}$
  - 16 Sections Total: $16 \times 12,294 = 196,704\text{ bytes}$
- Biomes: $256\text{ bytes}$
- **Strict Maximum Staging Size**:
  $$6 + 196,704 + 256 = 196,966\text{ bytes}\ (\approx 192.35\text{ KB})$$

**Capacity Setting**:
- Staging buffer is allocated at **262,144 bytes (256 KB)**.
- 256 KB provides a **$65,178\text{ byte}$ ($33.1\%$) guaranteed safety headroom** over the absolute worst-case legal chunk.
- M1.1's initial 128 KB buffer was correctly identified as insufficient for full 16-section global palette columns and upgraded.

### Output Buffer Maximum Capacity Proof
- Wire Section Header: $1\text{ byte}$ (bits)
- Palette Count: $1\text{ byte}$ (VarInt 0 for global, or 1..2 bytes for indirect)
- Palette Entries:
  - Indirect max (bits=8): 256 entries $\times$ 3 bytes max VarInt = $768\text{ bytes}$
  - Global: $0\text{ bytes}$
- Words Length VarInt: $2\text{ bytes}$
- Words Payload: $8,192\text{ bytes}$
- Block Light: $2,048\text{ bytes}$
- Sky Light: $2,048\text{ bytes}$
- Section Wire Max: $1 + 1 + 2 + 8,192 + 2,048 + 2,048 = 12,292\text{ bytes}$
- 16 Sections: $16 \times 12,292 = 196,672\text{ bytes}$
- Biomes: $256\text{ bytes}$
- **Strict Maximum Wire Output Size**:
  $$196,672 + 256 = 196,928\text{ bytes}\ (\approx 192.31\text{ KB})$$

**Capacity Setting**:
- Netty direct output capacity is sized with a **256 KB (262,144 bytes)** limit, strictly guaranteeing zero overflow on all valid Protocol 340 packets.

## 3. Error Codes & Recovery Semantics
| Error Code | Enum Name | Cause | Action |
| :--- | :--- | :--- | :--- |
| `-1` | `NullBufferPointer` | JNI direct buffer address is null/zero | Immediate Java fallback |
| `-2` | `OutputBufferOverflow` | Netty DirectByteBuf capacity $< \text{required}$ | Immediate Java fallback |
| `-3` | `InvalidSectionBitmask` | Bitmask popcount $\neq$ section count | Immediate Java fallback |
| `-4` | `UnsupportedPaletteWidth` | Bits per block $< 4$ or $> 16$ | Immediate Java fallback |
| `-5` | `RustPanicCaught` | Uncaught panic caught by `catch_unwind` | Immediate Java fallback; metrics increment |
| `-6` | `CorruptStagingData` | Buffer truncated or trailing unaccounted bytes | Immediate Java fallback |
| `-7` | `UnsupportedAbiVersion` | Header schema version $\neq 1$ | Immediate Java fallback |
| `-8` | `InvalidSectionIndex` | Index $\ge 16$, not in mask, or duplicate | Immediate Java fallback |
| `-9` | `PaletteOverflow` | Indirect palette count $> 256$ | Immediate Java fallback |
| `-10` | `MissingLightArray` | Staging buffer ended before lighting arrays | Immediate Java fallback |
